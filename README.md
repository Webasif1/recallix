
# Recallix 🧠

Recallix is an AI-powered knowledge management app designed to act as your second brain. It allows users to save content from across the internet and automatically organizes, connects, and resurfaces it when needed.

## 🚀 Features

- 🔖 Save anything (articles, links, videos, images, PDFs)
- 🧠 Smart tagging and organization
- 🔍 Search through saved content
- 🗂️ Collections and filters
- 🔗 Related content suggestions
- ⏰ Memory resurfacing (rediscover old saves)
- ✨ Highlight important content

## 🛠️ Tech Stack

### Frontend
- React (Vite)
- Tailwind CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB (Mongoose)

### Future Enhancements
- AI-based tagging (OpenAI)
- Semantic search (vector database)
- Graph visualization (D3.js)
- Browser extension

## 📂 Project Structure

- `/frontend` → React app
- `/backend` → Express API
- `/models` → Database schemas
- `/controllers` → Business logic
- `/routes` → API endpoints
